## Learned

- Preemption frees memory by evicting the youngest running sequence. When the only running sequence needs a new block, there is nobody to evict, and nano-vllm has no path for that case (#274).
- In nano-vllm, `max_model_len` only sizes buffers. It does not limit how long a sequence grows, which is behind both #274 and the CUDA Graph `block_tables` mismatch in #190.
- A request is admitted only if all its blocks fit at once. With a small cache, a long prompt waits in the queue even while other requests decode.
