## Learned

- Where a check lives matters as much as what it checks. The same size check inside the scheduler loop would have lost the request's output; in `postprocess`, it reuses the normal finish path.
- "Don't crash" is not the whole goal. The better question is who pays for the failure: the whole batch, or only the request that cannot fit.
- A PR needs a clean branch and evidence that others can reproduce. My local debugging options did not exist upstream, so I found an upstream setting (`gpu_memory_utilization`) to reproduce the bug on unmodified code.
